### 1. 홈(캘린더) — 보리 직접 검토·확정 (2026-09-08)

> 아래 6개는 보리가 직접 화면 캡처로 짚어주고, 감시관이 코드로 원인까지
> 확인한 뒤 확정한 것. 최초 자동 비교로 나왔던 "햄버거 메뉴 버튼 배경 차이"
> 항목은 실제로 동일해서(원본도 투명 배경) 삭제.

1. 🟡 **"년"/"월" 옆 아래 화살표(▼)** — react-app에만 있음("2026년⌄ 9월⌄"),
   원본은 순수 텍스트만("2026년 9월").
2. 🟡 **상단 헤더가 원본보다 위로 붙어있음** — 벨·로고·햄버거 메뉴, 날짜
   선택 알약까지 포함한 헤더 블록 전체가 react-app이 원본보다 위쪽에 바짝
   붙어있음(원본 대비 날짜 알약 시작 위치가 약 50px 정도 차이). 전체적으로
   아래로 내려야 함.
3. ✅ **벨/햄버거 아이콘 원형 배경 — 확인 결과 문제 아님.** 원본도 투명
   배경이라 육안으로는 안 보임, react-app도 마찬가지 — 실질적으로 동일.
   손대지 않음(보리 확인).
4. 🟡 **날짜 칸 클릭 시 하이라이트가 다크모드에서 흰색으로 뜸** — 원본은
   눌렀을 때 보기 편한 회색인데 react-app은 흰색이 튐. **원인 확정**:
   다크모드 배경색 변수(`--hover-bg`/`--today-bg`)가 [account-flow.css:25-36](react-app/src/account-flow.css:25)
   에서만 어두운 값으로 재정의되는데, [main-calendar.css:1-14](react-app/src/main-calendar.css:1)가
   같은 변수를 라이트 값으로 다시 선언하면서 코드 로딩 순서상 이게 나중에
   적용돼 다크모드에서도 라이트 색이 이겨버림.
5. 🟡 **"차량 정비비" 텍스트 색** — 원본은 빨간색(`--sunday-color`), react-app은
   기본색. **원인 확정**: 원본 CSS `.summary-row.maint { color: var(--sunday-color); }`
   [style.css:1293](ubiquitous-parakeet/style.css:1293)가 정비비 행에 적용되는데
   react-app [CalendarMonthSummary.jsx](react-app/src/components/calendar/CalendarMonthSummary.jsx)의
   정비비 행엔 색상 지정이 아예 없음. **결정: 색만 빨간색으로 맞추고, 원본에
   있는 굵게(font-weight:700)는 넣지 않는다(보리 결정).**
6. 🟡 **하단 네비 "마이페이지" 글자가 "마이페이"/"지"로 줄바꿈됨** — 칸 폭은
   둘 다 60px로 동일한데, react-app의 폰트 지정(`system-ui, "Segoe UI",
   sans-serif`)이 원본(`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
   "Helvetica Neue", Arial, sans-serif`)보다 짧아서, 이 환경에서 "마이페이지"를
   그리는 데 더 넓은 폭(57.6px, 원본은 52.99px)이 필요해 60px 칸에서 줄바꿈됨
   (실측 확인, 실제 사용자 기기별로 정확한 폭은 다를 수 있음).

그 외 캘린더 그리드·요일·칩·"월간 운송료 정산" 카드의 나머지 항목(거래처별
행·부가세·합계 등)은 구조·숫자 동일(③ 슬라이스에서 이미 원본과 맞춤 확인됨).

### 1-1. 메뉴(사이드메뉴) — 보리 직접 검토·확정 (2026-09-08)

> 화면 인벤토리 13개와 별개로, 모든 화면에서 공통으로 열리는 좌측 사이드메뉴.
> 보리가 직접 캡처로 짚어주고 감시관이 코드로 원인까지 확인.

1. 🟡 **"관리"↔"경영" 섹션 순서가 반대** — CSS `order` 속성으로 실제 화면
   순서가 소스 순서와 다름(처음에 DOM 순서만 보고 "같다"고 잘못 판단했었음,
   재확인함). **원본 실제 화면**: 경영→관리→서류→설정. **react-app**:
   관리→경영→서류→설정("서류"/"설정" 순서는 둘 다 동일, 이 부분만 다름) —
   [style.css](ubiquitous-parakeet/style.css) 다크/라이트 섹션에 `order` 지정,
   [SideMenu.jsx](react-app/src/components/SideMenu.jsx)엔 없음(작성 순서 그대로 노출).
2. 🔴 **"2222 일지"(소속기사 차량) 옆 톱니바퀴(빠른 설정) 버튼이 react-app에
   없음** — 원본은 `showSubCarSettings()`로 그 차량 전용 설정 화면
   (`subCarSettingsPage`, [index.html:1389](ubiquitous-parakeet/index.html:1389))
   에 바로 들어감. react-app은 이 버튼 자체가 없고, 관련 설정이 "앱 설정"
   화면([AppSettingsPage.jsx](react-app/src/components/AppSettingsPage.jsx))
   맨 아래로 옮겨가 있음. **추가로 확인된 더 큰 문제**: 원본은 메인차량과
   기사(서브)차량의 "운행 일지 세부 입력" 토글 6종(달력표시방식·결제수금·
   운행시간·플랫폼·계기판·화물톤수)을 각각 따로 가지는데, react-app은
   이 설정값이 [practiceSettings.js](react-app/src/domain/practiceSettings.js)
   기준 **메인/서브 구분 없이 딱 한 벌뿐** — 화면 위치만 옮기는 수준이 아니라
   **서브차량 전용 데이터 필드 자체를 새로 만들어야 하는 작업**. 다음 감시관이
   범위를 다시 잡아야 함.
3. 🔴 **사이드메뉴 배너 이미지 — 다크/라이트 전용 이미지 2개가 통째로 누락**
   — 원본은 `images/banner_image_Light.png`·`images/banner_image_dark.png`를
   테마별로 각각 보여주는데([index.html:108-110](ubiquitous-parakeet/index.html:108)),
   react-app `public/images/`엔 이 두 파일 자체가 없고 범용
   `banner_image.png` 하나만 씀([SideMenu.jsx](react-app/src/components/SideMenu.jsx)) —
   이미지 안에 있던 "운행 일지" 글자를 없애고 대신 `<span>` 텍스트로 옆에
   붙여서 흉내만 냄. 보리가 직접 제작한 원본 이미지 파일을 그대로 써야 함.
4. 🔴 **"{기사이름} 기사 관리" 메뉴 항목 텍스트가 "기사 기사 관리"로 중복
   표시됨** — [SideMenu.jsx:165,169](react-app/src/components/SideMenu.jsx:165)
   `${item.driverName} 기사 관리` 템플릿에서, 연동된 기사의 이름이 비어
   있으면 `driverName`이 fallback 값 `"기사"`로 채워지면서
   (`LinkedDriverManagementPage.jsx:94` `link.driverName || '기사'`) "기사
   기사 관리"라는 중복 문구가 남. 이름이 실제로 비어 있는 게 정상 데이터
   상태인지, 이름 표시 자체가 문제인지 확인 필요.

### 1-2. 공용 헤더 스타일 — 보리 직접 확인 (2026-09-09, 2차)

## 2~14. 보리 직접 재조사 (2026-09-09, 2차) — 진행 중, 더 추가될 예정

> 아래는 감시관 자동 초안이 아니라 **보리가 직접 화면을 보며 찾은 내용**.
> "일단 적어놓고 내일부터 작업" — 아직 착수지시서 없음, 기록만 완료.
> 더 찾으면 이 목록에 계속 추가될 예정.

### 2. 마이페이지
- 앱 설정 좌측의 톱니바퀴 아이콘 아래가 찌그러져 있음(스타일 충돌인 듯).

### 3. 매출 (전체 손익 탭)
- "운임 수수료" 값이 0일 때 원본은 "-0원"(마이너스 부호 표시), react-app은
  "0원"(부호 없음) — 값 자체는 0이라 의미 없지만 표시 방식만 다름.

### 4. 일일운행 (오늘 운행 일지)
- "+추가"/분류칩 재클릭 시 닫기(토글) 기능 없음.
- 입력창 포커스 시 파란 라운드 테두리 전체 누락.
- 레이아웃 위치 자체가 전반적으로 틀어짐(개별 항목 아래 나열).
- 시간입력: 시계 아이콘 vs 원본 "시간 선택" 텍스트.
- 계기판: "km" 단위가 칩 안에 있어야 함.
- 상차지/하차지 필드 크기·색 다름.
- 글자 크기 전체적으로 불일치(입금예정일/비고/계산서/거래처/플랫폼/출발계기판 등).
- 정비/주유/기타: 날짜·누적거리 2단 그리드(50:50) 미구현.
- 정비/주유/기타: 결제방식이 세그먼트 컨트롤 디자인이 아님.
- **참고(보리)**: 닫혀 있으면 동일해 보이나 모달창을 열면 UI가 전부 달라서
  대조에 시간이 오래 걸릴 것으로 보임.

### 5. 차량 관리
- 카드에 표시되는 전화번호 제거, 원본처럼 "기사 연동"인지 "운행 일지"인지
  라벨칩 표시.
- **원본 카드는 수정/삭제가 아이콘인데 react-app 카드는 "수정"/"삭제"
  글자로 되어 있음 — 아이콘으로 변경 필요. 적용 대상: 차량관리·거래처·
  정비/주유/기타 공통.**

### 6. 거래처
- 고정노선 연동 칩이 원본은 파란색인데 react-app은 회색임.

### 7. 미수금/정산 관리
- 원본은 "월별 묶음 정산 / 입금 예정" 미수금이 그리드인데 react-app은
  토글 — 그리드로 변경 필요.
- react-app에만 안내 문구("운행 일지 세부 입력에서 자동으로 모읍니다.
  부분 입금은 상세에서 기록합니다.")가 있음 — 원본엔 없음.
- 버튼 문구 — react-app "상세"/"입금 완료"(짧게), 원본 "미수금 상세"/
  "입금 완료"(원본 표기 확인).
- 버튼 위치 — 미수금 금액 아래 가로 구분줄 아래, 하단으로 원본과 같이
  이동 필요.
- 금액 뒤 "원" 앞 띄어쓰기 — react-app "100,000 원"(띄움), 원본
  "100,000원"(붙임).
- 원본은 메인 차량을 파란색 네모 칩으로 표시.

### 8. 정비/주유/기타
- **"정비/주유/기타" 탭 위치가 반대** — react-app은 탭 3개가 화면 맨
  위(타이틀 바로 아래)에 있고, 원본은 탭이 목록 맨 아래("+추가" 버튼
  다음)에 있음.
- **월 합계 카드 위치·문구** — react-app "이번 달 정비 / 2건 / 합계
  1,300,000원"이 목록 위(맨 위)에 먼저 나오고 항목 개수("2건")도 표시.
  원본은 "9월 정비 / 합계 1,300,000원"이 목록 아래(항목들 다음)에 나오고
  개수 표시 없음.
- react-app 항목마다 "수정삭제" 버튼아이콘이 바로 보임(차량관리·거래처와
  같은 패턴), 원본엔 없음.
- 금액 뒤 띄어쓰기 계속 다름(react-app "400,000 원" / 원본 "400,000원").
- 날짜별 항목 내용(엔진/카드/엔진·미션, 금액)은 동일.

### 9. 세금계산서
- **"공급가" vs "공급가액" 레이블 다름** — react-app "공급가", 원본
  "공급가액"(더 정확한 세무 용어).
- **합계 줄에 라벨 없음** — react-app 카드는 "공급가 350,000원 / 세액
  35,000원 / 385,000원"(세 번째 숫자에 "합계"라는 라벨이 없이 숫자만),
  원본은 "공급가액/세액/**합계** 385,000원"으로 라벨이 붙어 있음.
- **카드별 "작성 전" 상태 뱃지 안 보임** — 원본은 개별 거래처 카드에도
  "작성 전" 상태가 표시되는데, react-app 카드엔 상단 요약("작성 전 1 /
  발급 완료 0")만 있고 카드 자체엔 상태 표시가 안 보임.
- 상단 탭 UI 상태 다름.
