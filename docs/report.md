### 목표 상태 (이번 슬라이스)

1. 확인 창 문구: "이 파일에서 지금 없는 것만 더합니다 — 일지 N일 · 거래처 a곳 · 지출 b건 · 세금계산서 c건". 0인 종류는 안 씀. 모두 0이면 "더할 기록이 없습니다".
2. 거래처: 같은 업체명(앞뒤 빈칸 무시)이나 같은 번호가 있으면 건너뜀. 새로 넣는 거래처의 옛 서버 번호는 지우고 새로 저장. 이미 고정노선 연결 거래처가 있으면 새로 넣는 거래처의 고정노선 연결은 끔(한 곳 규칙).
3. 지출: 같은 번호가 있으면 건너뜀. 차량이 메인(차량 번호 없음)이면 내 메인 차량, 번호가 있으면 **번호 같은 내 차량** — 없거나·서버에 없거나·연동 기사가 붙은 차량이면 건너뜀(22-A와 같은 규칙).
4. 세금계산서: 같은 번호가 있으면 건너뜀. 차량은 계산서의 차량 번호로 같은 규칙. 옛 서버 번호는 지우고 새 줄로 저장.
5. 저장 순서: **거래처 → 일지 → 지출 → 세금계산서**(일지·계산서가 거래처 이름을 서버 번호로 바꿔 쓰므로 거래처 먼저, 지출은 그날 일지에 붙으므로 일지 다음). 한 단계라도 실패하면 거기서 멈추고 안내 — 앞 단계는 저장된 채로 남고, 다시 불러오면 "없는 것"만 다시 잡힘.
6. 끝나면 "불러왔습니다 — 일지 N일 · 거래처 a곳 · 지출 b건 · 세금계산서 c건".
