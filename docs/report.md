## 로드맵 11번 1단계 — 홈 화면 앱(PWA): 주소창 없이 열기 `[x]`

보리 지시(2026-10-07): 주소창 없는 앱 모양으로 비교해 보고 싶음 → 로드맵 11번(PWA + 구글 플레이) 중 **PWA 부분만 먼저**, 도메인 구입 없이.
2단계(TWA·플레이 스토어·자체 도메인)는 이번 범위 아님.

### 현재 상태

- `manifest.webmanifest` 없음, 앱 아이콘(192·512px) 없음(`public/`에 `favicon.svg`·`images/`만).
- 그래서 휴대폰 크롬에서 "홈 화면에 추가"를 해도 **주소창 있는 일반 웹페이지**로 열림.
- 배포 주소 `https://mung2nyang.github.io/react-app/`(`vite.config.js` `base`), 깊은 주소는 `404.html` 복사로 처리(`ci.yml:50-52`), 라우터 `basename` 있음(`main.jsx:13`).

### 목표 상태 (기대 동작)

1. 휴대폰 크롬 메뉴에 **"앱 설치"(또는 "홈 화면에 추가")** 가 뜨고, 누르면 바탕화면에 트럭 아이콘 "운행 일지"가 생김.
2. 그 아이콘으로 열면 **주소창·브라우저 메뉴 없이 전체 화면**(위 휴대폰 상태바만 보임). 첫 화면은 앱 첫 주소(`/react-app/`)부터.
3. 앱 범위 = `/react-app/` 아래 전부. 그 밖(구글 로그인 창 등)으로 나가면 크롬이 자동으로 위에 작은 주소 띠를 보여 줬다가, 돌아오면 다시 사라짐(크롬 기본 동작).
4. 위 상태바 색: 앱 테마에 맞춤(라이트 `#f4f7f6` / 다크 `#121212`) — 이미 있는 첫 화면 테마 스크립트(`index.html:12-21`)에서 같이 지정.
5. 브라우저 탭으로 여는 기존 방식은 그대로 동작(비교 가능: 탭 = 주소창 있음, 설치 아이콘 = 주소창 없음).
6. 아이폰 사파리 "홈 화면에 추가"도 주소창 없이 열리게 아이폰용 표시 2줄 추가(로드맵상 아이폰은 대상 아님 — 덤, 확인은 안 함).

### 안 건드릴 것

- **서비스워커(오프라인 저장 장치) 안 넣음** — 넣으면 배포 후에도 옛 화면이 휴대폰에 남는 문제가 생길 수 있고, 지금 크롬은 서비스워커 없이도 설치가 됨.
  (휴대폰에서 "앱 설치"가 안 뜨면 그때 수정 착수지시서로 최소 서비스워커를 제안 — 임의로 추가 안 함, AGENTS §7.)
- `vite.config.js`·`ci.yml`·라우터 — 그대로(`public/` 파일은 빌드 때 그대로 복사되고, 주소 앞부분 `/react-app/`은 Vite가 붙임).
- 앱 화면 코드(`src/**`) — 테스트 파일 말고는 안 건드림.

### 실패 시 처리 — **신규 레이어 없음**

- 저장·동기화 무관. 설치가 안 되면 지금과 똑같이 웹페이지로 열릴 뿐(데이터 영향 없음).

### §6 200줄

- 새 파일 모두 작음. `index.html`은 화면 코드가 아니고 약 5줄만 늘어남.

### §8 질문 답

- 1~4: 저장·구독 무관. 5: 권한 변경 없음.

2. 설정 파일에 적힌 아이콘 그림이 실제로 있고 크기(가로·세로 픽셀)가 적힌 것과 같음.
3. `index.html`에 설정 파일 연결이 있음.
