## 배포까지 순서 7-D — 해제 시 기사 쪽 기록 보관 — 조사·설계 보고 (착수지시서 전)

기사 쪽은 **메인 일지**에 "배정차량 00가0000" 식 표시. 다시 해제할 때는 **이번 연동 기간만** 복사. 재할당 때는 차주 차량 버전을 따르고 기사 사본과 합치지 않음.
해제 뒤엔 차주·기사가 각자 고치고 지워도 서로 무관. 추가 `[확인: 2026-10-01 보리]`: 7-C-2의 카드 글씨 모양 수정도 7-D에 포함.

### 조사 — 지금 상태 (근거)
- 해제는 서버 함수 한 곳에서만 일어남: `disconnect_driver_link_internal`(0011:13) — 기사 동의·차주 동의·3일 처리 모두 여기로. **복사를 여기에 붙이면** 누가 해제하든 같은 순간에 한 번 실행됨.
- 기간: 연동 1건 = `driver_links` 1행(`assignment_start`~해제 때 넣는 `assignment_end`). 재연동은 새 행 → **그 행의 기간만 복사하면 "이번 기간만"이 자동으로 맞음**.
- 복사할 표 5개(모두 `vehicle_id`·`work_date`로 찾음): `daily_logs`(차량+날짜당 1줄, `raw`에 하루 정보) · `transport_details`(콜 — `client_id`는 **차주 거래처**를 가리킴, 거래처 이름은 `raw.client`에도 있음)
  · `fuel_records`·`maintenance_records`·`misc_expense_records`(모두 `daily_log_id`로 하루 줄에 매달림).
- 기사 계정의 메인 차량: 메인 차량은 사용자가 차량 관리에서 직접 등록할 때만 생김(`syncVehiclesClients.js:62`). 기사로 가입한 계정은 **자기 차량이 없을 가능성이 큼** → 복사할 곳이 없음.
- 일지 하루 정보는 정해진 이름만 읽음(`persistDayRecord.js:10` `DAY_RECORD_KEYS`, `hydrateMergeWork.js:39`) → "배정차량" 표시용 칸을 쓰려면 이 목록에 1개 추가 필요.

### 설계안
**7-D-1 서버(마이그레이션 0012):** `disconnect_driver_link_internal`이 상태를 바꾼 직후 같은 묶음에서 복사(복사가 실패하면 해제도 같이 취소 — 반쪽 해제 없음).

- 검증: 기사·차주 계정 가정으로 한 묶음 안에서 해제→복사 확인 후 되돌리기(7-C-1과 같은 방식). **실제 테스트 연동은 해제하지 않음.**

**7-D-2 화면:** 복사된 날의 일지에 "배정차량 00가0000" 표시(위치는 아래 질문 1) + 하루 정보 이름 목록에 1개 추가 + 소속 연결 카드 글씨 모양

### 결정·확인 요청
1. **"배정차량 00가0000" 표시 위치** — 예: ① 일일운행 입력 화면 날짜 옆 ② 달력의 그 날짜 칸 ③ 콜 목록 위 한 줄. 원하시는 곳을 알려 주세요.
2. **기사 계정에 메인 차량이 없을 때** — 추천: **배정 차량 번호로 메인 차량을 하나 만들어 거기에 복사**(기사가 나중에 번호를 바꿀 수 있음). 이미 메인 차량이 있으면 그 차량에 복사.
3. **거래처** — 추천: **복사한 콜에 나오는 거래처 중 기사 계정에 같은 이름이 없는 것만 거래처로 복사**(연동 중 기사에게 보이던 그 차량 거래처 정보 그대로).
   복사 안 하면 콜에 거래처 이름은 보이지만 기사 거래처 목록·거래처별 미수금에는 안 나옴.
4. **같은 날짜에 기사 메인 일지가 이미 있을 때**(예: 연동 시작일을 과거로 잡은 경우) — 추천: **기사 쪽 하루 정보는 그대로 두고 콜·비용만 뒤에 붙임**(덮어쓰지 않음).
5. 미수·입금 상태는 **그대로 복사**됨 → 기사 미수금 화면에 그대로 보임. 이대로 괜찮은지.
6. 위 설계와 슬라이스 2개(7-D-1 서버 → 7-D-2 화면+글씨)로 갈지.

### 결정 `[확인: 2026-10-01 보리]`
1. 표시 위치 = **① 일일운행 입력 화면 날짜 옆**. 3. 거래처 = 기사 계정에 같은 이름이 없는 것만 복사. 4. 같은 날짜 = 기사 하루 정보 유지, 콜·비용만 뒤에 붙임.
6. 슬라이스 2개(7-D-1 서버 → 7-D-2 화면+글씨).
2. 기사 계정 차량 = 해제 때 **배정 차량과 같은 번호의 차량을 기사 계정에 새로 만들어 메인으로** 복사(기사가 이미 메인 차량을 등록해 뒀으면 그 차량에). 해제 뒤 기사 것이라 차주 차량과 무관.

### 지시서 원문

### 1. 목적 (쉬운 말)
연동이 해제되는 순간(기사 동의·차주 동의·3일 자동 해제 모두) 서버가 **이번 연동 기간의 그 차량 기록 전부**를 기사 계정으로 복사한다.
기사 계정에는 배정 차량과 같은 번호의 메인 차량이 생기고, 일지·콜·주유·정비·기타 비용이 그 차량으로 들어간다. 이후 차주·기사가 각자 고쳐도 서로 영향 없음.

### 2. 서버 변경 (마이그레이션 0012, 멱등·한 묶음, 사용자 지시 시 AI가 SQL Editor에서 실행)
0. **먼저 읽기 전용 조회**(AGENTS §9): `vehicles`·`clients`·`daily_logs`·`transport_details`·`fuel_records`·`maintenance_records`·`misc_expense_records`의 칸·필수 여부·기본값·유일 제약·외래키.
   조회 결과로 아래 SQL의 칸 목록을 확정(추측 금지).
1. 내부 함수 `copy_driver_link_records_internal(연동 id)`(일반 사용자 실행 불가) — 그 연동의 차량·기사·`assignment_start`~`assignment_end`로:
   - **차량:** 기사 계정에 메인 차량이 있으면 그것, 없으면 배정 차량 번호·종류 정보로 메인 차량을 새로 만듦(작성자 = 기사, 기사·연동 관련 칸은 비움).
   - **거래처:** 복사할 콜의 거래처 중 기사 계정에 **같은 이름이 없는 것만** 차주 거래처 행을 기사 계정으로 복사. 콜의 거래처 연결은 기사 쪽 거래처(같은 이름)로 바꿔 넣음.
   - **하루 일지:** 날짜마다 기사 메인 차량에 하루 줄. 같은 날짜가 이미 있으면 **기사 하루 정보 그대로**, 없으면 차주 하루 정보 복사 + `raw.assignedVehicleNumber`(배정 차량 번호) 추가.
   - **콜·주유·정비·기타:** 그 날짜 하루 줄 아래로 복사(작성자 = 기사, 차량 = 기사 메인). 같은 날짜에 기사 기록이 있으면 **순서 번호를 그 뒤로** 붙임. 미수·입금 상태·입금 내역 **그대로**.
2. `disconnect_driver_link_internal` 수정 — 상태를 `disconnected`로 바꾼 직후 위 함수 호출. 같은 묶음이라 **복사 실패 시 해제도 취소**(반쪽 해제 없음).
   기사 계정이 이미 삭제돼 기사 칸이 비어 있으면 복사 생략.
3. 되돌리기 주석: `disconnect_driver_link_internal`을 0011 본문으로 다시 만들고 새 함수 삭제(이미 복사된 기사 쪽 기록은 남음).
