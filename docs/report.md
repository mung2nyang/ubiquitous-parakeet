### 1. 목적 (쉬운 말)
개발 모드(`npm run dev`)에서 일지 화면을 **열기만 해도 0.6초 뒤 자동 저장이 도는 것**과, 저장이 끝나도 **"저장 중…"이 계속 떠 있는 것**을 고친다.
실사용(배포) 앱에는 두 증상이 없지만, 테스트 중 원치 않는 저장(0-3 사고의 방아쇠)과 잘못된 저장 상태 표시를 막는다.

### 2. 원인 (코드로 확인)
개발 모드의 React `StrictMode`(`main.jsx:12`)는 화면을 열 때 "켜기 → 끄기 → 다시 켜기"를 한 번 흉내 낸다.
- **열기만 해도 저장:** `useDayDraft.js:150-153`이 "처음 한 번은 저장 안 함"을 `isFirstDraftRef` 표시로 막는데, 첫 켜기에서 표시를 써 버리고 다시 켜기에서
  "편집됨"으로 보고 600ms 뒤 저장을 건다.
- **"저장 중…" 안 사라짐:** `dayDraftLifecycle.js:12-16` `useMountedRef`가 끄기 때 "화면 닫힘"으로 바꾸고 다시 켜기 때 "열림"으로 되돌리지 않는다 →
  저장이 성공해도 `markSaved`가 "화면이 닫혔다"고 보고 상태를 "저장됨"으로 안 바꾼다(`useDayDraft.js:85`).

### 3. 목표
- 열기만 해서는 저장이 돌지 않는다 — "처음 값과 같은 draft면 저장 안 함"으로 판정(표시 대신 처음 draft 자체와 비교, 두 번 켜져도 같은 결과).
- 화면이 다시 켜지면 "열림"으로 되돌린다 → 저장 성공 시 "저장됨" 표시.
- 편집하면 지금처럼 600ms 뒤 저장, 화면을 나가면 밀린 저장 flush — 무변경.

### 4. 건드릴 파일 (react-app)

2. `src/components/day-log/dayDraftLifecycle.js`(45줄) — `useMountedRef`가 켜질 때 `true`로 되돌림(1줄).
