### 1. 목적 (쉬운 말)
일상점검표를 저장할 서버 표를 만들고, 누가 보고 쓸 수 있는지 정한다. 연동 해제 때 점검표도 기사 계정으로 복사되게 한다. 화면은 9-B부터.

### 2. 서버 변경 (마이그레이션 0014, 멱등·한 묶음, AI가 SQL Editor에서 실행 — 보리 지시 2026-10-01)
1. 새 표 `daily_inspections`: `id uuid` 기본키(자동), `user_id uuid` → profiles(계정 삭제 시 비움), `vehicle_id uuid` 필수 → vehicles(차량 삭제 시 함께 삭제), `work_date date` 필수,
   `items jsonb` 필수(기본 `{}`, 객체여야 하고 값은 `"good"`/`"bad"`만), `action_note text`, `inspector_name text`, `created_at`·`updated_at timestamptz`(기본 지금),
   유일(`vehicle_id`,`work_date`). 보안 규칙(RLS) 켬. `updated_at`은 수정 때 자동 갱신(트리거 1개).
2. 내부 판단 함수 `vehicle_has_linked_driver_on(차량, 날짜)` — 그 차량에 지금 연동 중이고 그 날짜가 연동 기간 안인 기사가 있으면 참(보안 정의자, `search_path = public`).
3. 권한 4개:
   - 조회: 내 차량(`vehicles.user_id = 나`) 또는 `driver_can_access_vehicle_date`(7-B).
   - 작성: 작성자 = 나 이고, (`driver_can_access_vehicle_date` 또는 (내 차량이고 `vehicle_has_linked_driver_on`이 거짓)).
   - 수정·삭제: (`driver_can_access_vehicle_date` 또는 (내 차량이고 `vehicle_has_linked_driver_on`이 거짓)).
4. `copy_driver_link_records_internal` 다시 만들기(0013 본문 그대로 + 1단계): 이번 연동 기간 그 차량 점검표를 기사 메인 차량으로 복사(작성자 = 기사, 같은 날짜에 기사 것이 있으면 기사 것 유지).
5. 되돌리기 주석: 표·함수·권한 삭제, 복사 함수는 0013 본문으로.
