## 배포까지 순서 8 — 모달 바깥 클릭으로 입력 날아감 + 사이드메뉴 배경 스크롤 `[x]` (착수지시서 확정 2026-10-01)

### 1. 목적 (쉬운 말)
배포 페이지 휴대폰 실사용 중 발견한 불편 2가지(로드맵 8번, 옛 순서 2번 상세 2026-09-17).
① 차량·거래처·정비/주유/기타 등 **입력 창 바깥을 잘못 누르면 창이 닫히며 적던 내용이 날아감** → 입력 창은 바깥을 눌러도 안 닫히게(취소·저장 버튼으로만 닫힘).
② **사이드메뉴를 연 상태에서 뒤 화면(회색 영역)이 스크롤됨** → 메뉴가 열려 있는 동안은 메뉴 안에서만 스크롤. 빈 곳(회색) 누르면 닫히는 동작은 유지.

### 2. 조사 — 지금 상태 (근거)

- React에서 바깥(`.modal-overlay`) 클릭으로 닫히는 창 11곳. 그중 **입력 칸이 있는 창 5곳**:
  `cars/CarFormModal.jsx:75`(차량) · `clients/ClientFormModal.jsx`(거래처) · `ExpenseFormModal.jsx:177`(정비·주유·기타) · `DriverFormModal.jsx`(기사 초대) · `TaxInvoiceDraftModal.jsx`(세금계산서 작성).
  입력 없는 창 6곳(확인 창 `ConfirmModal`·비밀번호 찾기 안내·보고서 상세·보고서 공유·알림 패널·메시지 문구 시트)은 바깥 클릭 닫힘이 편의라 그대로.
  일지 콜 입력(`InlineSheet.jsx`)은 원래 바깥 클릭으로 안 닫힘.
- 사이드메뉴: 회색 영역 `.side-menu-overlay`(고정, `side-menu.css:3`)와 메뉴 `.side-menu`(고정·자체 스크롤, `side-menu.css:11`). 화면 스크롤 주체는 문서 전체(`html`, 브라우저에서 확인) →
  메뉴가 열려 있어도 회색 영역 위 스크롤·메뉴 끝에서 넘친 스크롤이 뒤 화면을 움직임. 스크롤 잠금 코드는 지금 없음.

   JS 변경 없음(`SideMenu.jsx`는 이미 224줄 — 손대지 않음). 메뉴가 닫히면(요소가 사라지면) 잠금도 자동 해제.
