### 현재 상태 (코드 확인)

- 카드: `CalendarMonthSummary.jsx`(138줄). 금액은 `domain/monthSettlement.js:147-148`
  — 부가세 = (운송료 + 파렛트) × 10%, **합계 = 운송료 + 파렛트 − 거래처 수수료 − 기사차량 수수료 + 부가세**.
- 합계 줄 **아래**에 차량 정비비·주유비·통행료/기타가 나오지만 합계에선 **빼지 않음**(따로 보여 주기만) → 빼진 건지 아닌지 알 수 없음.
- 거래처 수수료 줄 `○○ 수수료 (10%)` / `(5,000원)` — 거래처 등록 때 적은 수수료 설정대로 그 거래처 운송료에서 뺌(`monthSettlement.js:93-127`). 왜 빠지는지 설명 없음.
- 기사차량 수수료 줄(기사차량 운행일지 화면에서만) `○○ 차량 10%` / `건당 ○원` — 차량 관리에 적은 이 차량 수수료 설정대로,
  (운송료 + 파렛트 − 거래처 수수료) 기준으로 계산해 뺌(`monthSettlement.js:132-141`).

### 목표 상태 (기대 동작)

1. 아래 세 종류 줄의 이름 옆에 작은 (i) 버튼. 누르면 그 줄 바로 아래에 회색 작은 글씨 설명이 펼쳐지고, 다시 누르면 접힘. 여러 개 동시에 펼칠 수 있음.
   - (i) 버튼은 눈에 보이는 크기는 작게(약 16px), 누르는 영역은 44px(14번 기준). 줄 높이는 안 늘어남.
   - 화면 읽기 기능: "합계 설명 보기" 같은 이름 + 펼침/접힘 상태 전달.
2. **설명 문구 초안** (보리 확인 후 확정):
   - **합계**: "운송료 + 파렛트 회수 청구액 − 수수료 + 부가세예요. 아래 정비비·주유비·통행료는 합계에서 빼지 않은 이번 달 차량 지출 기록이에요."
   - **거래처 수수료** (`○○ 수수료`): "거래처 등록 때 적은 수수료(10% / 건당 ○원)만큼 이 거래처 운송료에서 빼요."
     — 괄호 안은 그 줄의 실제 설정 값을 그대로 넣음.
   - **기사차량 수수료**: "차량 관리에 적은 이 차량의 수수료(10% / 건당 ○원)예요. 운송료에서 거래처 수수료를 뺀 금액을 기준으로 계산해 빼요."
