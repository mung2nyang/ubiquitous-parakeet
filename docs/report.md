## 로드맵 18-B — 터치 손질(아이폰 입력칸 확대·길게 누르기·진동) `[x]`

보리 확인(2026-10-08): 로드맵 18번 6개 전부 진행, 슬라이스 범위는 AI가 정함.

### 현재 상태 (코드 확인)

- **아이폰 입력칸 확대**: 아이폰은 글씨가 16px보다 작은 입력칸을 누르면 화면을 저절로 확대하고 안 돌려놓음. 지금 입력칸 글씨 13.3px(브라우저 확인), 앱 글씨 단계도 0.75~0.92rem(`variables.css:7-10`).
  화면 확대 설정은 `index.html:11` `width=device-width, initial-scale=1.0`뿐.
- **길게 누르기**: 버튼을 길게 누르면 글자 선택·복사 메뉴(아이폰은 미리보기 메뉴)가 뜸. 막는 규칙 없음(`user-select`·`-webkit-touch-callout` 0건, `grep`).
  횟수 버튼 설정은 "길게 누르면 삭제"(`RunCountChips.jsx:80`)라 이 메뉴가 같이 뜰 수 있음. 앱 안에 글자 복사 기능은 없음(`복사`·`clipboard` 화면 코드 0건).
- **진동**: 없음(`vibrate` 0건). 저장·삭제·오류 안내는 모두 화면 아래 안내 문구(`showToast`, 화면 코드 약 110곳)로 뜨고, 띄우는 곳은 `useAppSession.js` 한 곳(4초 뒤 사라짐 `:108-112`).

### 목표 상태 (기대 동작)

1. **아이폰**: 입력칸을 눌러도 화면이 확대되지 않음. **손가락 두 개로 벌려 확대는 그대로 됨**(아이폰은 iOS 10부터 이 설정으로 손가락 확대를 막지 않음). 입력칸 글씨 크기는 지금 그대로.
   **안드로이드·컴퓨터는 아무것도 안 바뀜**(안드로이드는 원래 저절로 확대 안 함, 손가락 확대 막지 않으려고 아이폰에만 적용).
2. **버튼·링크·그림을 길게 눌러도** 글자 선택·복사·미리보기 메뉴가 안 뜸. 입력칸·글 상자 안 글자 선택·붙여넣기는 그대로.
3. **안내 문구가 뜰 때 짧게 한 번 진동**(0.01초) — 저장·삭제·오류 안내 모두. 안드로이드만(아이폰 브라우저는 진동 기능 자체가 없어 조용히 넘어감).
   휴대폰이 무음·진동 끔이면 휴대폰 설정을 따름.
