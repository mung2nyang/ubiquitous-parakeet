# docs/report.md — 현재 슬라이스 착수지시서

## 로드맵 18-C — 휴대폰에서 누른 뒤 색이 남는 문제 `[x]`

보리 확인(2026-10-08): 로드맵 18번 6개 전부 진행, 슬라이스 범위는 AI가 정함.

### 현재 상태 (코드 확인)

- 마우스를 올렸을 때 색이 바뀌는 규칙(`:hover`)이 휴대폰에선 **누른 뒤에도 그 색이 남음**(다른 곳을 누르기 전까지). 마우스 있는 기기에서만 나오게 막는 규칙 없음(`hover: hover` 0건, `grep`).
- `:hover` 규칙 전체 12곳(`grep ":hover"`) 중 대상 11곳(6개 파일):

| 파일 | 줄 | 대상 | 지금 줄 수 |
|---|---|---|---|
| `components/calendar/calendar.css` | 79 | 달력 날짜 칸 | 251 |
| `components/shared/app-dropdown.css` | 22·85·110 | 선택 상자·선택지 | 123 |
| `controls-common.css` | 117·118 | 상단 알림·메뉴 버튼 | 143 |
| `header-controls.css` | 38·65 | 월 선택·좌우 화살표 | 103 |
| `management-common.css` | 75·80 | 목록 수정·삭제 아이콘 | 166 |
| `side-menu.css` | 121 | 사이드메뉴 항목 | 134 |

- 제외 1곳: `shared-controls.css:87` `.input-box:-webkit-autofill:hover` — 자동완성 입력칸 색을 모든 상태에서 고정하는 규칙(마우스 효과 아님), 그대로.
- 누를 때 반응은 "화면 다듬기 3"(`4e1e456`)의 버튼 눌림 효과(살짝 작아짐)가 이미 모든 버튼에 있음(`app-shell-base.css`).

### 목표 상태 (기대 동작)

1. **휴대폰**: 위 11곳을 눌렀다 떼면 색이 원래대로 돌아옴(누르는 동안은 눌림 효과). 색이 남지 않음.
2. **컴퓨터(마우스)**: 지금과 똑같이 마우스를 올리면 색이 바뀜.
3. 선택 상자 선택지의 "고른 항목"·"키보드로 고른 항목" 색은 그대로(마우스 올림만 분리).

### 방법

- 각 `:hover` 규칙을 "마우스 있는 기기에서만"(`@media (hover: hover)`) 묶음으로 감쌈. 색 값·선택자는 안 바꿈.
- `app-dropdown.css:84-86`은 고른 항목·키보드 선택과 한 규칙이라, 마우스 올림만 떼어 묶음 안에 같은 값으로 둠.

### 건드릴 파일

위 표 6개 파일(CSS만). 줄 수 변화: `app-dropdown.css` ~131, `controls-common.css` ~145, `header-controls.css` ~105, `management-common.css` ~168, `side-menu.css` ~136.

  분리설계는 이번 범위 밖(따로 필요하면 별도 슬라이스). 이 한 줄 수정을 예외로 승인 요청.
