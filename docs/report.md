## 배포까지 순서 7-C-1 — 양쪽 동의 해제: 서버 + 차주 화면 `[x]` (착수지시서 확정 2026-09-30)

> 완료(2026-09-30): react-app `3b36acb`(마이그레이션 0011), 브라우저 확인·push·CI 초록·§5 리뷰 통과·사용자 최종 승인. 주석 정정 react-app `32acee2`.

### 1. 목적 (쉬운 말)
차주가 "연동 해제"를 누르면 바로 끊기지 않고 **기사에게 해제 요청**이 간다. 기사가 동의하거나 요청 후 3일이 지나면 해제된다. 기사가 먼저 요청했으면 차주는 [동의]할 수 있다.
해제되면 연동 정보를 지우지 않고 "해제됨"+종료일로 남긴다. 서버에서도 이 규칙을 우회할 수 없게 막는다.

### 2. 서버 변경 (마이그레이션 0011, 멱등·한 묶음, 사용자 지시 시 AI가 SQL Editor에서 실행)
- `driver_links`에 `unlink_requested_by uuid`(→ profiles, 계정 삭제 시 비움)·`unlink_requested_at timestamptz` 추가.
- 내부 함수 `disconnect_driver_link_internal(연동 id)`: 상태 `disconnected`, 종료일 = 오늘, 요청 칸 비움(일반 사용자 실행 불가). **7-D가 여기에 기사 쪽 기록 복사를 붙임.**
- 사용자용 함수(그 연동의 차주·기사 본인만, 대상은 `linked`만):
  `request_driver_unlink(id)`(상대가 이미 요청했으면 곧바로 해제) · `consent_driver_unlink(id)`(상대 요청에 동의 → 해제) · `cancel_driver_unlink(id)`(내 요청 취소) ·
  `settle_expired_driver_unlinks()`(내 연동 중 요청 후 3일 지난 것 해제, 처리 건수 반환).
- 우회 차단: 연동 표에 변경 감시(트리거) — 일반 사용자가 직접 `linked`를 다른 상태로 바꾸거나 요청 칸을 고치면 거절(서버 함수 안에서만 허용).
  삭제 규칙 "차주만 초대 삭제"를 **`linked`가 아닌 행만** 삭제 가능으로(초대 취소는 그대로).
- 요청 중에도 상태는 `linked` → 기록 공유·7-A 탈퇴 막기·7-B 권한은 해제 확정까지 그대로.
