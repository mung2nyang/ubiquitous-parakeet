### 현재 상태
- 매출·마이페이지 등 17개 화면은 처음 누를 때 화면 파일을 받는다(`src/app/lazyPages.js`).
  받는 동안 `AppShell.jsx:144`의 `<PageSkeleton />`이 뜬다.
- 지금 뼈대는 어느 화면이든 같다: 가운데 제목 막대 1 + 맨바닥에 막대 3줄 묶음 3.
  카드 틀이 없어 실제 화면(카드들)과 모양이 전혀 다르다.
- 이 화면들은 서버 자료를 기다리지 않는다(자료는 휴대폰 안 저장소에서 바로 읽음 —
  `MyPage.jsx`는 `useOwnerProfile`·`useOwnerDrivers`만 씀). 기다리는 건 화면 파일뿐이라,
  일상점검표 안내처럼 "진짜 카드 먼저 + 안쪽만 불러오기"는 불가 → 같은 모양의 틀을 대신 그린다.

### 목표 상태 (기대 동작)
1. **마이페이지** 대기 중: 진짜 머리줄("마이페이지" 제목 + 메뉴 버튼) →
   개인정보 카드와 같은 크기·모서리·바탕의 카드 틀(안에 동그라미 + 막대 2줄) →
   "업무 바로가기" 자리 막대 + 아이콘 자리 6칸(4+2, 동그라미 + 짧은 막대) →
   아래 목록 자리 4줄(동그라미 + 막대).
2. **매출** 대기 중: 진짜 머리줄("매출" 제목 + 메뉴 버튼) → 위쪽 카드 틀(날짜 줄 자리 +
   년/월 탭 자리) → 카드 틀 2개(안에 막대 3줄).
3. **나머지 화면** 대기 중: 제목 막대 + 카드 틀 3개(일상점검표 안내 카드와 같은 테두리·
   모서리 18·카드 바탕·그림자, 안에 막대 3줄).
4. 화면 파일이 다 오면 진짜 화면으로 바뀔 때 카드 위치가 거의 그대로여야 한다
   (마이페이지·매출 기준).
5. 라이트/다크 둘 다 카드 틀·막대가 자연스럽게 보인다. 움직임 줄이기 설정이면 빛이 안 지나간다(기존 그대로).
6. 화면 읽기 프로그램용 "불러오는 중" 알림은 그대로 유지.
