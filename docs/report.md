## 새 홈 1단계 — 하단 탭 정리 + "오늘" 카드만 있는 새 홈 `[x]`

보리 요청 2026-10-10(로드맵 밖). 목업 확인 후 결정: 하단 탭 **홈 · 운행 · 매출 · 마이페이지**(4개 유지),
"운행" 탭 = 지금 달력(누르면 달력부터), 날짜 누르면 지금처럼 일지 화면. 일지 팝업 방식은 안 함.
**react-app 브랜치 `new-home`에서 진행**(main 배포 안 됨, 다 끝나면 main에 합침). 휴대폰 확인은 같은 와이파이로 PC 개발 서버 접속.
원래 순서상 다음이던 출시 전 1단계 ⑥ 23·24는 main에서 따로 할 수 있음.

전체 계획(이번은 1단계만):
- **1단계(이번)**: 주소·탭 정리 + 새 홈에 "오늘" 카드 하나.
- 2단계: 오늘 카드에 운행 줄 목록 + "할 일" 카드 + "이번 달 운송료" 한 줄.
- 3단계(미정): 운행 탭 달력 화면 머리 정리(로고 겹침) 등 다듬기.

### 현재 상태 (코드 확인)
- `/app` = 달력(`MainPageRoute` → `CalendarPage`), `/app/day/날짜` = 일지(`DayLogPage`).
- 하단 "일일운행" 탭 = 오늘 일지 바로가기(`AppShell.jsx:129`, `state.from='bottomNav'`면 일지 뒤로가기 숨김 `MainPageRoute.jsx:115`).
- 탭 강조: `/app`·서브차량 달력 `/app/logs/번호` = 홈, 일지 = 일일운행(`AppShell.jsx:104-112`).

### 목표 상태 (기대 동작)
1. 하단 탭 4개: **홈 · 운행 · 매출 · 마이페이지**. "운행" 아이콘은 지금 달력 아이콘 그대로.
2. **운행 탭** → `/app/calendar` = 지금 달력 화면 그대로(월 이동 `?y=&m=` 포함). 날짜 누르면 지금처럼 일지, 일지 뒤로가기 → 달력.
3. **홈** `/app` = 새 화면: 위쪽 줄(알림 종·로고·메뉴, 지금 달력 머리와 같은 모양) + **"오늘" 카드**
   - 날짜 "10월 10일 (금)"
   - 기록 없으면 "아직 기록이 없습니다" + [운행 기록하기], 있으면 "오늘 3회"(또는 운송료 입력 방식이면 달력 칸과 같은 금액 글자) + [하나 더 기록]. 휴무로 저장했으면 "오늘은 휴무입니다".
   - 버튼 → 오늘 일지 화면. 일지 뒤로가기 → 홈.
   - 숫자는 달력 칸 글자를 만드는 기존 함수(`dayWorkBadgeLabel`) 그대로 — 새 계산 없음.
4. 탭 강조: `/app`·서브차량 달력 `/app/logs/번호` = 홈(서브차량 달력은 지금 그대로 — 보리 결정), `/app/calendar`·`/app/day/*`·서브차량 일지 = 운행, 매출·마이페이지 그대로.
5. 그대로인 것: 앱 켜면 `/app`(이제 새 홈), 로그인·연동 후 `/app`, "한 번 더 누르면 종료"는 홈에서, 화면 전환(탭끼리 서서히), 사이드메뉴·알림.
6. 잘못된 날짜 주소·없는 서브차량 주소 → 지금은 `/app`으로 보냄 → `/app/calendar`로. 서브차량 달력의 "메인으로" → `/app/calendar`.
7. 저장·계산·데이터는 전혀 안 바뀜.
