### 결정·확인 요청
1. **21일** — 법정 서식 날짜 머리에 21일이 빠져 있음(1~20 다음 22). 추천: **21일 넣어 1~31일**(서식 인쇄 실수로 보임, 빼면 21일 기록을 못 적음). 다른 방법: 서식 그대로 21일 빼기.
2. **점검자 확인(서명) 줄** — 날짜 칸이 아주 좁음(가로 A4에 31칸). 추천: 그날 점검표의 **점검자 이름을 작은 글씨로**(넘치면 칸 안에서 줄바꿈), 점검표 없는 날은 빈칸.
   다른 방법: 이름 첫 글자만 / 줄은 비워 두고 출력 후 손 서명.
3. **[공유]** — 추천: 작은 창 "점검표 보내기"에 **[PDF로 보내기][이미지로 보내기]** 2개 → 기기 공유(카카오톡 등)로 파일만 보냄. 문자(거래처 연락처)·안내 문구는 없음(점검표는 거래처에 보내는 서류가 아님).
   다른 방법: 창 없이 바로 PDF 공유.
4. **브라우저 확인 때 파일 내려받기** — PDF·이미지가 제대로 나오는지는 실제로 만들어 봐야 알 수 있음. AI가 내장 브라우저에서 시험 파일 2개(PDF·PNG, 각 1MB 안쪽 예상)를 내려받아 열어 보고 지워도 될지.
5. **조치 기록 칸** — 그 달 점검표에 적힌 조치 기록을 **"N일 내용"으로 날짜 순 한 줄씩**(9-B-2에서 받은 그대로). 많으면 글씨 크기는 그대로 칸이 아래로 늘어남(한 장 안). 이대로 할지.
