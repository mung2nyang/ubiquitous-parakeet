## 로드맵 26 — 연동 기사에게 배정 기간 보여 주기 + 기간 밖 날짜는 입력 막기 `[x]`

로드맵 "출시 전 순서 개편" 1단계 ②. 원래 기록(2026-09-17): "기사가 왜 이 날짜 운행이 정산에 안 잡히는지 알 수 없음" — ⓐ 기사 계정에 연동 시작일 표시 ⓑ 시작 전 날짜 입력 시 경고.

### 현재 상태 (코드 확인)

- **기사 계정엔 배정 기간이 안 보임**: 개인정보 → "소속 연결" 카드(`drivers/EmployerLinkCard.jsx:63`)는 "연동 중 · 운송사 · 배정 차량 ○○"만. 기간 값은 이미 있음 — 기사 계정이 불러오는 연결 정보에 `startDate`·`endDate`(`lib/hydrateMerge.js:87`, 서버 `assignment_start`·`assignment_end`).
- **기간 밖 날짜는 이제 "정산에서 빠짐"이 아니라 "저장 자체가 거절됨"**: 7-B(DB `0010`, 2026-09-30)부터 서버 권한 규칙이 연동 기사의 운행·비용 기록을 **배정 기간 안 날짜만** 쓰고 읽게 함(`supabase/migrations/0010_driver_access_by_link_period.sql:8-25·36-40` — 시작일 전·종료일 뒤면 거절). 그런데 앱 일지 화면(`day-log/DayLogPage.jsx`)은 기사에게도 모든 날짜에 입력칸을 그대로 보여 줌 → 기사가 입력하면 서버가 거절 → 이유 없이 "저장에 실패했습니다." 토스트만(`lib/dayLogCloudCommit.js:136-137`). 2026-09-17 기록 때보다 상황이 나빠짐(그땐 저장은 되고 정산에서만 빠졌음).
- 일지 화면은 이미 "기사 계정인지"를 받음(`DayLogPage.jsx:59-61` `isEmployedDriver`). 날짜가 기간 안인지 보는 함수도 있음(`domain/drivers.js:152` `isDateWithinAssignment`).
- 차주 계정은 해당 없음(자기 차량은 모든 날짜를 씀 — DB 규칙도 그대로).
- 실서버로 기사 계정 재현은 안 함(실제 DB에 거절 기록을 남기게 됨) — 코드·DB 규칙으로 확인.

### 목표 상태 (기대 동작)

1. **소속 연결 카드**에 한 줄 추가: **배정 기간 2026-10-01 ~ 종료일 없음**(종료일이 있으면 그 날짜). 차량 관리 화면의 계약기간 표시와 같은 모양.
2. **연동 기사가 배정 기간 밖 날짜의 일지를 열면**: 제목은 그대로, 입력칸(휴무·고정 노선·세부 입력·지출·일상점검) 대신 안내만 보임 → 입력 자체가 안 돼서 거절당할 일이 없음.
   - 시작일 전: **배정 기간 전 날짜입니다. / 10월 1일부터 기록할 수 있습니다.**
   - 종료일 뒤: **배정 기간이 끝난 날짜입니다. / 12월 31일까지 기록할 수 있습니다.**
   - (문구는 보리 확인 — 바꾸고 싶으면 말씀)
3. 기간 안 날짜, 차주 계정, 비회원은 지금과 똑같음.
