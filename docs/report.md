# docs/report.md — 현재 슬라이스 착수지시서

## 로드맵 17번 — 홈 화면 앱 뒤로가기 "한 번 더 누르면 종료" `[x]`

보리 결정(2026-10-07): 방식 **② "한 번 더 누르면 종료" 안내**, 10-P보다 **먼저 지금**.

### 현재 상태 (코드 확인)

- 바탕화면 아이콘(11번 1단계 PWA)으로 연 앱에서, 첫 화면(홈 `/app`)에서 뒤로가기를 누르면 **확인 없이 바로 앱이 닫힘**(더 돌아갈 기록이 없어서).
- 뒤로가기를 따로 붙잡는 코드 없음(`popstate` 처리 없음 — `grep`). 화면 이동은 `AppShell.jsx:67-71` `navigate`(저장 안전 확인 `confirmLeaveIfUnsafe` 포함)를 거침.
- 안내 문구 띄우기는 기존 `showToast`(4초 표시, `useAppSession.js:110`).
- 라우터(react-router 7.18)는 이번 접속에서 몇 번째 기록인지(`idx`)를 브라우저 기록에 같이 적어 둠 → `idx`가 0이면 "여기서 뒤로가면 앱이 닫힘".

### 목표 상태 (기대 동작)

1. **바탕화면 아이콘으로 연 앱 + 홈 화면 + 더 돌아갈 화면이 없을 때만** 동작:
   - 뒤로가기 1번 → 앱이 안 닫히고 화면 아래 **"뒤로가기를 한 번 더 누르면 종료돼요"** 안내(4초).
   - 안내가 떠 있는 **4초 안에** 한 번 더 → 앱 종료. 4초 지나면 다시 처음(1번 누르면 안내)부터.
2. 다른 화면(일일운행·매출 등)에서 뒤로가기, 또는 홈이라도 앞서 본 화면이 있으면 → **지금처럼** 그 앞 화면으로 감.
3. **브라우저 탭으로 연 경우엔 지금과 똑같음**(아무것도 안 붙잡음).
4. 알려진 한계(브라우저 규칙, 못 막음): 앱을 열고 화면을 **한 번도 안 누른 채** 바로 뒤로가기를 누르면 안내 없이 닫힐 수 있음(보리 확인 2026-10-07).

### 방법

- 홈에 들어왔고 위 1번 조건이면, 같은 홈 주소로 "붙잡기용 기록"을 하나 더 쌓음(화면은 그대로). 뒤로가기를 누르면 그 기록만 빠지고 홈에 그대로 있음 →
  그때 안내를 띄우고 4초 동안은 붙잡기 기록을 다시 안 쌓음(그 사이 또 누르면 진짜 첫 기록에서 뒤로 → 앱 종료). 4초 뒤 다시 쌓음.
- 붙잡기 기록은 라우터의 `navigate`로 쌓아 라우터 기록과 어긋나지 않게 함(저장 안전 확인을 거치지 않는 원래 `navigate` 사용 — 같은 홈 주소라 화면 이동이 없음).

### 테스트 (`useBackToExit.test.js`)

1. 조건 함수: 설치 앱 + 홈 + 첫 기록일 때만 "붙잡기", 브라우저 탭·다른 화면·앞 기록 있음이면 안 붙잡음.
