# docs/report.md — 현재 슬라이스 착수지시서

## 로드맵 21 — 당겨서 새로고침을 우리 앱 모양으로 `[x]`

보리 지시(2026-10-08): 크롬 기본 동그란 화살표 대신 우리 앱 색·모양, 당기면 화면 전체 다시 불러오기, 설치 앱 전용.

### 현재 상태 (코드 확인)

- 화면 맨 위에서 아래로 당기면 **크롬 기본** 동그란 화살표가 나오고 놓으면 새로고침(보리 스크린샷 — 설치 앱에서도 나옴). 앱 코드엔 당겨서 새로고침 처리 없음(`overscroll-behavior`는 일상점검 시트·날짜 선택·사이드메뉴 안쪽 3곳만, 화면 전체엔 없음 `grep`).
- 화면 스크롤은 **문서 전체**(일일운행도 안쪽 스크롤 영역 없음 — `.work-log-page`는 여백만, `overflow-y: auto`는 팝업 폼·알림 패널·사이드메뉴·선택 상자·날짜 선택·일상점검 시트 안쪽뿐). → "맨 위" = 문서 스크롤 0. (앞서 대화에서 "일일운행 안쪽 스크롤"이라 한 건 틀림 — 정정.)
- 팝업·사이드메뉴·알림 패널·날짜 선택·선택 상자는 모두 화면 고정(`position: fixed`) 또는 안쪽 스크롤 상자.
- 저장 덜 끝난 상태로 나가기 확인: `confirmLeaveIfUnsafe`(`lib/durableWriteGuard.js`, 화면 이동에 이미 사용).

### 목표 상태 (기대 동작)

1. **설치 앱에서만**: 크롬 기본 화살표를 끄고, 화면 맨 위에서 아래로 당기면 **우리 앱 표시**(카드색 동그라미 + 파란 화살표)가 위에서 손가락을 따라 내려옴(당긴 거리의 절반만 움직여 묵직하게, 최대 약 90px). 당길수록 화살표가 돎.
2. 충분히 당기면(표시가 약 70px 내려온 지점) 표시가 파란 바탕으로 바뀜 → **놓으면** 표시가 빙글빙글 돌며 **화면 전체 다시 불러오기**. 덜 당기고 놓으면 제자리로 쏙 들어감.
3. 다시 불러오기 전 **저장이 덜 끝났으면 기존 확인 창**(`confirmLeaveIfUnsafe`)을 거침 — 취소하면 그대로.
4. **동작 안 함**: 화면이 맨 위가 아닐 때, 손가락이 팝업·사이드메뉴·알림 패널·날짜 선택·선택 상자 등 **화면 고정 상자나 안쪽 스크롤 상자 안**에서 시작할 때, 위로 미는 동작, 손가락 두 개.
5. **브라우저 탭으로 열면 지금처럼 크롬 기본 화살표**(아무것도 안 바꿈). 로그인·처음 설정 화면도 그대로(앱 안 화면에서만).
6. "애니메이션 제거" 설정이면 화살표가 돌지 않고 표시만 내려옴.
