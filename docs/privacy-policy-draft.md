## 운행 일지 개인정보처리방침

운행 일지(이하 "운영자")는 운행 일지 서비스(이하 "서비스") 이용자의 개인정보를 「개인정보 보호법」에 따라 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

### 1. 개인정보의 처리 목적

운영자는 다음 목적을 위해 개인정보를 처리합니다. 목적이 바뀌면 미리 동의를 받는 등 필요한 조치를 합니다.

1. 회원 식별과 로그인(구글 계정 로그인), 회원 관리
2. 운행 일지·운송 내역·차량 유지비·미수금 기록 저장과 여러 기기에서 이어 쓰기
3. 운송비 내역서·세금계산서 작성 자료·일상점검표 등 서류 만들기
4. 차주와 소속 기사 사이의 연동(초대, 연동, 해제)과 기록 공유
5. 고객센터 문의 접수와 답변

### 2. 처리하는 개인정보 항목

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 필수 (회원가입·로그인) | 구글 계정 이메일, 이름, 프로필 사진 주소, 구글 계정 고유 번호 | 구글 로그인 시 구글로부터 제공 |
| 필수 (첫 로그인) | 이름, 휴대전화 번호 | 이용자 직접 입력 |
| 선택 (개인정보·사업자 정보) | 상호, 사업자등록번호, 대표자 이름, 사업장 주소, 업태, 종목, 세금계산서 이메일, 은행 이름, 계좌번호, 예금주 | 이용자 직접 입력 |
| 서비스 이용 기록 | 차량 번호·차종, 운행 날짜, 상차지·하차지, 운송료·수수료, 정비·주유·기타 비용, 미수금, 세금계산서 작성 정보, 일상점검표(점검자 이름 포함), 앱 설정 | 이용자 직접 입력 |
| 연동 (차주·기사) | 기사 이름, 휴대전화 번호, 배정 차량, 연동 기간 | 차주가 초대할 때 입력, 기사가 초대 코드로 연동 |
| 고객센터 | 문의 유형, 제목, 내용 | 이용자 직접 입력 |

- 이용자가 거래처·기사 등 **다른 사람의 정보**(이름, 전화번호, 사업자 정보 등)를 입력하는 경우, 그 정보는 이용자의 업무 기록으로만 저장·표시되며 운영자는 다른 목적으로 쓰지 않습니다. 이용자는 그 사람에게 필요한 동의를 받는 등 관계 법령을 지켜야 합니다.
- 서비스는 위치 정보(GPS), 카메라, 연락처를 수집하지 않습니다.
- 비회원으로 이용하면 입력한 정보는 서버로 보내지 않고 이용자 기기(브라우저)에만 저장됩니다.

### 3. 개인정보의 처리 및 보유 기간

1. 회원 정보와 서비스 이용 기록은 **회원 탈퇴 시까지** 보유하고, 탈퇴하면 지체 없이 파기합니다.
2. 다만 **소속 기사로 연동된 차주의 차량**에 기사가 입력한 운행·비용 기록은 그 차주의 업무 장부에 속하므로, 기사가 탈퇴해도 작성자 표시만 지우고 차주 장부에 남습니다.
3. 연동 중인 계정은 연동을 먼저 해제해야 탈퇴할 수 있습니다.
4. 운행·정산 기록은 이용자 본인의 업무 장부입니다. 세무 신고 등에 필요한 기록은 탈퇴 전에 서류 발급 화면에서 운송비 내역서(PDF)·세금계산서(엑셀)·일상점검표(PDF)로 내려받거나,
   마이페이지의 데이터 다운로드로 내 기록 전체를 파일로 내려받아 보관하시기 바랍니다(차주·개인 회원). 탈퇴하면 서버의 기록은 복구할 수 없습니다.

   【법정 보존 기간(전자상거래법 3년·국세기본법 5년)은 넣지 않음 — 무료 서비스라 통신판매업자 의무 해당 없음, 장부 보존은 이용자(사업자) 본인 의무, 적으면 그만큼 실제로 보관해야 하는데 지금은 탈퇴 시 바로 삭제. 유료화하면 다시 검토】

### 4. 개인정보의 파기 절차 및 방법

- 탈퇴하면 계정과 개인정보·사업자 정보, 이용자 본인 차량의 기록을 서버에서 지웁니다(제3항 2호 예외 제외).
- 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 종이 문서는 만들지 않습니다.
- 이용자 기기(브라우저)에 남은 정보는 로그아웃·브라우저 데이터 삭제로 이용자가 지울 수 있습니다.

### 5. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음은 이용자가 직접 하는 일입니다.
- **차주·기사 연동:** 연동하면 연동 기간의 해당 차량 운행·비용 기록, 차주의 사업자·정산 계좌 정보(기사 화면에 보기 전용)가 연동 상대에게 보입니다.
- **공유 기능:** 운송비 내역서·일상점검표를 PDF·이미지로 만들어 문자·카카오톡 등으로 보내는 것은 이용자 기기에서 이용자가 받는 사람을 정해 직접 보냅니다.

### 7. 이용자의 권리와 행사 방법

- 이용자는 언제든지 자신의 개인정보를 조회·수정할 수 있습니다(마이페이지 → 개인정보).
- 회원 탈퇴(마이페이지 → 개인정보 → 회원 탈퇴)로 처리 정지와 삭제를 요청할 수 있습니다.
- 그 밖의 열람·정정·삭제·처리정지 요청은 고객센터 1:1 문의나 아래 개인정보 보호책임자에게 하시면 지체 없이 조치합니다.

### 8. 개인정보의 안전성 확보 조치

- 데이터는 이용자 본인(과 연동 상대)만 읽고 쓸 수 있도록 서버에서 행 단위 접근 권한(Row Level Security)으로 막습니다.
- 모든 통신은 암호화(HTTPS)합니다.
- 비밀번호는 서비스가 받지 않습니다(구글 로그인).
- 관리자 계정 접근을 운영자로 제한합니다.

### 9. 자동으로 수집하는 장치의 설치·운영 및 거부

- 서비스는 광고·분석용 쿠키나 추적 도구를 쓰지 않습니다.
- 로그인 상태 유지와 빠른 화면 표시를 위해 브라우저 저장소(localStorage)에 로그인 정보와 기록 사본을 저장합니다. 브라우저 설정에서 사이트 데이터를 지우면 삭제되며, 이 경우 다시 로그인해야 합니다.
