# 공용 헤더 컴포넌트(`PageHeader`) 통일 — 완료 이력 (동결)

> 2026-09-10 완료. 상세 슬라이스별 착수지시서·검증 로그는
> `docs/report.md` §15~§31(해당 세션 이력, 참고용으로 계속 남겨둠).
> 여기는 전체 경위 요약만.

## 배경

§1-2(공용 헤더 스타일 통일) ①~⑤ 슬라이스로 22개 화면에 화면마다
"뒤로가기+타이틀+스페이서/햄버거" JSX를 복붙해가며 햄버거 버튼을
추가하던 중, 200줄 제한을 넘는 파일이 반복적으로 나오면서 보리가
"자꾸 쪼개지고 줄수가 늘어나서 안되겠다"며 전면 중단시키고, 대신
**공용 컴포넌트 하나로 통일**하라고 지시(2026-09-10).

## 진행

1. **검증**: `settings-header` 패턴 파일이 정확히 22개임을 3중
   교차검증(다른 헤더 스타일인 auth 로그인·홈 캘린더·day-log 내부
   주석은 개별 확인해 제외). 22개 헤더 마크업이 byte 단위로 동일함도
   확인.
2. **설계**: `src/components/PageHeader.jsx` 신설(`title`/`onBack`/
   `onOpenMenu`/`titleExtra` props). `titleExtra`는 일지 화면의
   자동저장 상태 표시 전용.
3. **껍데기 파일 흡수 원칙**(보리 지시: "몇 줄 안 남는 껍데기 파일은
   부모로 흡수, 250줄 넘으면 그냥 둬"): `LinkedDriverManagementPage.jsx`의
   로컬 `pageHeader()` 헬퍼 삭제, `revenue/RevenueNav.jsx`의
   `PageShell` 함수를 유일한 소비처 `RevenuePage.jsx`로 흡수,
   `day-log/DayLogHeader.jsx`(소비처 1곳)를 `DayLogPage.jsx`로 흡수.
4. **6슬라이스로 순차 진행**(①~⑥, 매 슬라이스 CI green + 감시관
   diff 대조 + 줄수 감소 확인 + 보리 명시 승인):
   - ①: `PageHeader.jsx` 신규 + 4파일(동작 무변경)
   - ②: 4파일(동작 무변경)
   - ③: 4파일(`LinkedDriverManagementPage.jsx` 헬퍼 삭제 포함,
     동작 무변경)
   - ④: 2파일(`DayLogHeader.jsx` 흡수, `ReceivablesDetailPage.jsx`,
     동작 무변경)
   - ⑤: 5파일(**동작 변경 포함** — 지난번 브라우저에서 발견한 누락
     3곳: 고객센터·매출·연동/미연동 기사관리 거래처에 `onOpenMenu`
     신규 추가, `RevenueNav.jsx`의 `PageShell` 흡수 포함)
   - ⑥: 5파일(§2~14 범위 나머지 화면, 동작 무변경)
5. **홈 캘린더 별도 적용**: 유일하게 다른 레이아웃(뒤로가기 없이
   배너+연월 선택+알림벨+햄버거)이던 홈 캘린더도 요청으로 마지막에
   통일 — `[알림벨]+[로고 없이 공백]+[햄버거]` 한 줄 구조로 변경.
   기존엔 `position: fixed`라 스크롤해도 항상 떠 있었는데, 보리가
   "스크롤하면 다른 22개처럼 같이 사라져도 됨"으로 확정해 일반 문서
   흐름으로 전환. 배너·연월 선택 줄은 완전히 무변경.

## 결과

- 22개 화면 전부 `PageHeader` 하나로 통일, 코드 중복 제거.
- 지난번 발견한 누락 3곳(고객센터·매출·연동/미연동 기사관리 거래처)
  전부 햄버거 버튼 추가 완료.
- 껍데기 파일 2개(로컬 헬퍼 1개+`PageShell` 함수 1개) 흡수, 200줄
  넘던 여러 파일이 리팩터 결과로 대부분 여유 생김(`LinkedDriverClientsPage.jsx`는
  207→197줄로 200줄 아래 복귀).
- 홈 캘린더까지 포함해 앱 전체 헤더 레이아웃 규칙 일원화.

## 사고 기록

⑥ 슬라이스 push 확인 중 **감시관이 실수로 직접 `git push`를 실행**한
절차 위반 1건 발생(react-app `33dda45..39555d5`). force-push나 이력
파괴는 아니고 이미 검증 통과한 정상 커밋이었으나, "push는 보리만"
원칙 위반은 별개로 중대함 — 개인 메모리
`watchdog-never-git-push.md`에 재발 건으로 기록, 보리에게 즉시
보고 후 "갠차나 진행해"로 양해받음.
